Безопасная локальная демонстрация ReDoS

Болорболд Аригуун, Ladybird

Обе регулярки принимают непустую строку из одних a и отвергают строку с другим символом.

Уязвимая: /^(a+)+$/
Безопасная: /^a+$/
Вход: "a".repeat(n) + "!"

Готово к запуску.

n
Результат
Время, мс

Отчёт об исследовании

  1. Тестирование проводилось в Ladybird.
  2. Для обоих выражений использовалась строка "a".repeat(n) + "!". Поэтому результат проверки в каждом случае — false.
  3. В форме были заданы максимальное N = 40 и максимальное время одного измерения 300 мс. n начиналось с 10 и увеличивалось на 2.
  4. Перед каждым вызовом regexp.test(value) фиксировалось performance.now(). После вызова фиксировалось второе значение; разница записывалась в таблицу.
  5. Безопасное выражение /^a+$/ прошло до n = 40. В таблице все значения отображены как 0.000 мс.
  6. Для /^(a+)+$/ время росло с увеличением n: 3.2 мс при n = 16, 45.1 мс при n = 20, 767.7 мс при n = 24, 3.1199 с при n = 26, 14.997 с при n = 28 и 52.519 с при n = 30. На n = 26 прогон был остановлен, потому что был превышен предел 300 мс, но для полной картины принялось решение дополнительно сделать измерения до n = 30.
  7. Ladybird имеет встроенную защиту от ReDoS атак, и в отличие от многих браузеров, невозможно отключить через настройки: Для эксперимента пришлось изменить самого кодового источника следующим образом:
    1. Увеличение константа лимиты допустимых итерации до остановки поиска (находится в файле Libraries/LibRegex/Rust/src/vm.rs, строки 17-18): 
      
            /// Maximum number of steps before aborting (prevents ReDoS).
            - const MATCH_LIMIT: u64 = 10_000_000;
            + const MATCH_LIMIT: u64 = 1_000_000_000_000;
    2. Для бенчмаркинга пришлось также добавить следующую строку в функциях run_fast и run_general: 
      
              if self.steps >= MATCH_LIMIT {
              + eprintln!("[MATCH_LIMIT] steps={}", self.steps);
                return VmResult::LimitExceeded;
              }
      Это позволяет получить результаты выполнения на каждой итерации в виде консольной строки, ибо в Ladybird на данный момент отсутствуют встроенные графические инструменты для профилирования.
    После пересборки через эту команду из корневой директории (обязательно в sh/bash): 
    
          MAKEFLAGS="-j1" LDFLAGS="-fuse-ld=gold" makepkg -si -e
    Если отсутствует линковщик, то нужно будет либо его установить, либо использовать lld, так как линковщик по умолчанию в моем случае (CachyOS/yay [вспомогательная утилита для установки пакет из AUR]) во всех протестированных случаях потреблял настолько памяти, что ОС пришлось использовать OOM Killer над самим консольным приложением (в моём случае, fish), тем самым прервав процесс.
  8. Также приходилось собрать PKGBUILD из нуля для VPN, чтобы скачивать Ladybird из AUR (Arch User Repository, пользовательский репозиторий Arch), так как доступа к источнику кэша (vcpkg) закрыли некая группа людей с тремя буквами. Сам VPN был в формате .deb, что не дружит с ОС-ами семейства Arch Linux как сам Arch Linux, CachyOS, Artix и Manjaro. Сам разработчик не рассматривал поддержку для систем Arch в ближайшее время.
